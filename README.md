## Що вміє
- Розділяє готову пісню на доріжки: вокал, барабани, бас, гітара, клавішні, інше — або створює проєкт з нуля.
- Переводить їх у MIDI, визначає темп, сильну долю, тональність, акорди й структуру.
- Редактор: монтаж кліпів, піано-рол, редактор висоти голосу, автотюн, ефекти, інструменти, мікшер із шинами й сайдчейном, аналізатор і мастеринг.
- Вокальна студія із живим автотюном, генератор партій, бібліотека семплів, історія проєкту.
- Відеостудія: відео треку для TikTok, Reels, Shorts, YouTube та Instagram.
- Експорт: готова пісня в MP3 і WAV, окремі доріжки, MIDI, семпли й звуковий гід. Стандартні формати відкриваються в будь-якій музичній програмі — FL Studio, Ableton Live, Logic Pro, GarageBand, Cubase, Studio One, Reaper, Bitwig, LMMS.

## Встановлення
| Система | Файл | Як |
|---|---|---|
| Windows 10/11 | `InkBeat-Setup-Windows.exe` | Запустити й натиснути «Встановити» |
| macOS 11+ | `InkBeat-macOS.zip` | Розпакувати, перенести в «Програми», правий клік → «Відкрити» |
| Linux | `InkBeat-Setup-Linux.run` | `chmod +x InkBeat-Setup-Linux.run && ./InkBeat-Setup-Linux.run` |

Python окремо не потрібен. Під час встановлення потрібен інтернет (≈0,6 ГБ, ≈3 ГБ з прискоренням NVIDIA). Детально — у файлі [ПРОЧИТАЙ МЕНЕ.txt](ПРОЧИТАЙ%20МЕНЕ.txt).

## Оновлення
Встановлена програма сама бере оновлення з цього репозиторію: під час запуску перевіряє номер версії і, якщо він новіший, завантажує й встановлює код ще на екрані завантаження.

## Як випустити нову версію (для розробника)
1. Змініть `VERSION` у `app/engine/project.py` (наприклад, `2.3.1`) і додайте розділ `## 2.3.1` у `CHANGELOG.md` — цей текст програми покажуть у «Що нового».
2. Завантажте змінені файли в гілку `main`.

Цього достатньо: усі встановлені програми побачать нову версію під час наступного запуску. Паралельно GitHub Actions збере свіжі інсталятори для Windows, macOS і Linux і опублікує реліз — вони потрібні лише для нових користувачів.

Репозиторій має бути **публічним**, інакше програми не зможуть завантажувати оновлення.
