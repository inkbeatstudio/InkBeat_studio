INKBEAT — пісня на редаговані доріжки для FL Studio
=====================================================

ЩО ВМІЄ
• Бере готову пісню (MP3, WAV, FLAC, OGG, M4A) або окремі доріжки (стеми).
• Розділяє мікс на доріжки: вокал, барабани, бас, гітара, клавішні, інше.
• Переводить доріжки в MIDI: вокальна мелодія, бас, акорди й партії клавішних і гітари,
  барабани (бочка, малий, хети, тарілки, томи у розкладці General MIDI для FPC).
• Визначає темп, сильну долю, тональність, акорди та структуру (інтро, куплет, приспів…).
• Редактор: різання, переміщення, дублювання кліпів і доріжок, ефекти на кожну доріжку,
  інструменти для MIDI, автотюн, шумоподавлення, зміна тону, мікшер і Master.
• Експорт для FL Studio: MIDI, вирівняні стеми, оброблені доріжки, повний мікс,
  семпли з пісні, лупи в темпі та звуковий гід з порадами щодо плагінів FL.
• Запис голосу чи інструмента з мікрофона поверх пісні, зміна темпу й тональності,
  своя бібліотека семплів і пресетів, історія проєкту, пакетна обробка кількох пісень.

ДЕ ЗАВАНТАЖИТИ
Остання версія завжди на сторінці релізів GitHub (посилання — у меню «Довідка →
Перевірити оновлення… → Сторінка релізів»):
  • Windows 10/11 — InkBeat-Setup-Windows.exe
  • macOS 11+ (Apple Silicon та Intel) — InkBeat-macOS.zip
  • Linux (x86_64, ARM64) — InkBeat-Setup-Linux.run
Python та інші програми окремо ставити не треба. Під час встановлення потрібен інтернет:
≈0,6 ГБ (≈3 ГБ з прискоренням відеокартою NVIDIA), 5–20 хвилин.

ВСТАНОВЛЕННЯ — WINDOWS
1. Запустіть InkBeat-Setup-Windows.exe. Якщо Windows покаже «Захист ПК» —
   «Докладніше → Усе одно запустити».
2. Компоненти: «Прискорення відеокартою NVIDIA» (розбір у кілька разів швидший) і ярлик.
3. «Встановити». Права адміністратора не потрібні. Якщо крок не вдався — «Повторити».
4. Запуск — ярлик InkBeat. «Діагностика InkBeat» у «Пуску» — запуск із вікном повідомлень.
   Видалення — «Параметри → Програми → InkBeat» (проєкти залишаються).

ВСТАНОВЛЕННЯ — macOS
1. Розпакуйте InkBeat-macOS.zip і перетягніть InkBeat у папку «Програми».
2. Перший запуск: програма без платного підпису Apple, тому macOS її блокує.
   Клацніть InkBeat правою кнопкою → «Відкрити» → «Відкрити». На macOS 15 і новіших:
   спробуйте відкрити, потім «Системні параметри → Конфіденційність і безпека» →
   «Усе одно відкрити».
3. Відкриється вікно «Термінал» із встановленням (8 кроків). Після «Готово!» InkBeat
   запуститься сам. Далі просто відкривайте його з «Програм».
   На Apple Silicon (M1–M4) розбір іде на відеокарті Mac.

ВСТАНОВЛЕННЯ — LINUX
1. Відкрийте термінал у папці із завантаженим файлом і виконайте:
     chmod +x InkBeat-Setup-Linux.run && ./InkBeat-Setup-Linux.run
2. Програма ставиться у ~/.local/share/InkBeat (без sudo), з'являються ярлик у меню
   програм, на робочому столі й команда «inkbeat». Відеокарта NVIDIA визначається сама.
3. Якщо інсталятор напише, що бракує бібліотек Qt, InkBeat відкриватиметься у браузері.
   Для окремого вікна (Ubuntu/Mint/Debian): sudo apt install libxcb-cursor0 libnss3
4. Видалення: ~/.local/share/InkBeat/uninstall.sh (проєкти залишаються).

ОНОВЛЕННЯ (усі системи)
• InkBeat сам перевіряє оновлення під час запуску. Коли виходить нова версія, вона
  завантажується у фоні, а після перезапуску програми починає працювати.
• «Довідка → Перевірити оновлення…» — перевірити вручну, прочитати «Що нового»
  і вимкнути автоматичне встановлення, якщо хочете оновлюватися самі.
• Проєкти, бібліотека й налаштування під час оновлення не зачіпаються.
• Без інтернету: «Файл → Оновити програму з архіву…» і файл InkBeat-update.zip.

ЯК КОРИСТУВАТИСЯ
•  Відео для соцмереж: кнопка «Відео» вгорі → формат (9:16 TikTok/Reels/Shorts, 16:9 YouTube,
   1:1 Instagram), стиль, назва й нік → «Записати відео». MP4 — у папці проєкту «video».
0. Свій трек з нуля: картка «З нуля» на головному екрані → темп, тональність, довжина →
   «+ Додати доріжку» (MIDI-інструменти, барабани, аудіо з файлу, запис з мікрофона).
1. «Новий розбір» → режим «Готова пісня» (один файл) або «Готові стеми» (кілька файлів
   чи папка). Ролі стемів визначаються за назвою файлу: Vocals, Backing Vocals, Drums,
   Percussion, Bass, Guitar, Keys/Piano, Synth, Strings, Brass, Woodwinds, FX.
2. «Розібрати». Пісня на 3–4 хвилини: на відеокарті 1–2 хвилини, на процесорі 3–8 хвилин.
3. Редактор. Пробіл — відтворення. Клік на назву доріжки відкриває внизу її мікшер,
   ефекти, інструмент і обробку. Довідка — кнопка «? Довідка» вгорі або F1.
   Унизу екрана рядок підказок: наведіть мишку на будь-яку кнопку.
4. «Експорт у FL Studio» → «Відкрити папку». У FL Studio: File → Import → MIDI file →
   «… - all tracks.mid» (або «… - edited arrangement.mid»), галочка «Start new project».

РЕДАГУВАННЯ (коротко)
• Кліпи: ніж (C), подвійний клік або S — розрізати; тягнути — перемістити; краї — обрізати;
  жовті квадратики — плавний вхід і вихід; Ctrl+D — дублювати; Ctrl+C/V; Delete; M.
• Ctrl+Z / Ctrl+Y — скасувати і повторити (до 80 кроків).
• Меню «⋯» біля назви доріжки — дублювати доріжку з окремими ефектами й обробкою.
• Панель каналу (F9):
  – Ефекти: еквалайзер, компресор, гейт, лімітер, сатурація, фільтр, хорус, дабл, дилей,
    ревер, стерео, тремоло, lo-fi, автотюн, гармонайзер, де-есер; готові ланцюжки для
    вокалу (зокрема з автотюном), баса, барабанів і Master.
  – Інструмент: синтезатор із пресетами, семплер зі звуків пісні, драм-кіт.
  – Обробка звуку: автотюн, зміна тону, шумоподавлення, прибрати інші інструменти,
    де-есер, тиша між фразами, нормалізація, реверс. Оригінал зберігається у «Версіях».
    Перед застосуванням натисніть «Прослухати»: фрагмент звучить по колу, перемикач
    «До / Після» (клавіша A) порівнює з оригіналом, ручки можна крутити під час прослуховування.
• Автоматизація (кнопка A на доріжці): гучність, панорама, фільтр у часі.
• Аналізатор: спектр, гучність LUFS, пік, порівняння з референсом, мастеринг одним
  кліком під Spotify / Apple Music / соцмережі / клуб. Мікс експортується в MP3 і WAV.

ЗВЕДЕННЯ
• Вкладка «Мікшер»: пульт з фейдерами, індикаторами, панорамою, виходами й посилами.
• Шини: спільний Ревер / Дилей, Паралельна компресія, Групи. Експортуються окремо.
• Ефекти: Сайдчейн (бас «дихає» з бочкою), Багатосмуговий компресор, Динамічний EQ,
  Транзієнт-шейпер.
• «Помічник зведення»: баланс гучності, конфлікти частот, поради одним кліком.

ФІНІШ І РОБОЧИЙ ПРОЦЕС
• Аналізатор → «EQ під референс»: тембр міксу підганяється під улюблений трек.
• «Перевірка»: моно, телефон, навушники, ноутбук, машина, клуб; фаза й ширина стерео.
• Експорт: Інструментал, А капела, Мінус для виступу, стеми барабанів / баса / музики.
• «Клавіші»: грати й записувати ноти мишкою, клавіатурою комп'ютера або MIDI-клавіатурою.
• Маркери з нотатками (Ctrl+M), заморожування доріжок (меню ⋯) для легкої роботи.

VST, ОЧИЩЕННЯ, БАРАБАНИ
• Інструменти → «VST-плагіни…»: ваші VST3-ефекти й VST3-інструменти (Serum, Vital, Kontakt…).
  Ефект — «Обробка звуку» → «VST-плагін»; інструмент — вкладка «Інструмент (MIDI)».
  Плагіни лише у форматі VST2 (.dll) не підтримуються.
• «Обробка звуку»: Цифрові артефакти, Прибрати реверберацію, Відновити верхи,
  Заміна барабанів, Квантування аудіо.
• Цикл (L) і запис у межах циклу; автоматичні кросфейди між кліпами.

ОНОВЛЕННЯ І ЗВІТ ПРО ПРОБЛЕМУ
• Нова версія: «Файл» → «Оновити програму з архіву…» → виберіть InkBeat.zip.
  Проєкти й бібліотека не зачіпаються, нові бібліотеки доставляються самі.
• Щось не працює: «Довідка» → «Звіт про проблему…» — файл звіту з'явиться на робочому
  столі, надішліть його.

ВИГЛЯД І ПАНЕЛІ
• Межі між панелями тягнуться мишкою (подвійний клік — стандартний розмір).
• «Вигляд» → готові розкладки (Стандарт, Аранжування, Зведення, Редагування нот,
  Запис вокалу, Мінімум) і збереження своїх; теми, колір акценту, компактний режим.
• Масштаб інтерфейсу: Ctrl + / Ctrl − / Ctrl 0. На весь екран: F11.

ЗАПИС, ТЕМП, БІБЛІОТЕКА, ІСТОРІЯ
• «Запис» — вокальна студія. Вкладка «Голос і ефекти»: готові звуки голосу (Автотюн: поп,
  Hard-tune, Реп з автотюном, Бек-вокал: хор, Хелій, Демон, Робот…) і власний ланцюжок
  ефектів, який чути в навушниках під час запису. Вкладка «Запис»: курсор → червона кнопка
  або R; відлік, метроном, караоке, запис по колу (кожне коло — дубль), тюнер, графік
  вашого голосу поверх мелодії оригіналу з відсотком влучання в ноти. Вкладка «Текст» —
  суфлер. Найкращий дубль — «Зберегти доріжкою»: ефекти голосу переходять на доріжку.
  Записуйте в навушниках.
• Вкладка «Висота нот»: редактор висоти голосу нотами — тягніть ноти вгору-вниз, ставте
  в лад, вирівнюйте «пливучу» висоту й вібрато. Змінюється лише те, що ви змінили.
• Інструмент «Збірка» (B): ідеальний дубль із кращих шматків кількох дублів.
• «Обробка звуку»: Вирівняти за часом (дабли під головний вокал), Вдихи й клацання,
  Вокал-райдер (рівна гучність голосу).
• Нові вокальні ефекти для будь-якої доріжки: Автотюн (у реальному часі), Гармонайзер
  (терції, квінти, октави в тональності), Де-есер.
• «Темп / тон»: новий BPM і тональність усієї пісні. Створюється новий проєкт, поточний
  не змінюється. Барабани висоту не змінюють; для голосу найкраще ±1–3 півтони.
• «Бібліотека»: свої семпли (у семплер і на пади драм-кіта) та збережені пресети
  синтезатора, ефектів і ланцюжків. Спільна для всіх проєктів.
• «Історія»: знімки стану проєкту з відновленням; автозбереження кожні 10 хвилин.
• Пакетна обробка: на сторінці «Новий розбір» виберіть кілька пісень і поставте галочку
  «Це різні пісні — розібрати кожну окремо».

ПРОЄКТИ ЗБЕРІГАЮТЬСЯ ТУТ
   Документи\InkBeat Projects\
   Проєкти з попередньої версії переносяться сюди автоматично.
   Бібліотека семплів і пресетів: Документи\InkBeat Projects\_library\

МЕЖІ
• MIDI передає ноти, а не звук: тембр, ефекти й текст пісні в нотах не зберігаються.
  Вокал стає мелодією; сам голос беріть зі стему або з оброблених доріжок.
• Найточніше розпізнаються барабани, бас, вокальна мелодія й прості акорди. Густі гітари
  з дисторшном і багато ревербу дають зайві ноти: регулюйте чутливість доріжки або
  чистіть ноти скриптом «InkBeat Cleanup» у Piano roll FL Studio.
• Окремі стеми у WAV дають чистіший результат, ніж розділення готового міксу.

СКРИПТ ДЛЯ PIANO ROLL FL STUDIO
   Скопіюйте «InkBeat Cleanup.pyscript» у
   Документи\Image-Line\FL Studio\Settings\Piano roll scripts
   і запускайте в Piano roll: Tools → Scripting → InkBeat Cleanup.
   Працює з виділеними нотами або з усіма, якщо нічого не виділено.

ЯКЩО ЩОСЬ НЕ ТАК
• «InkBeat ще не встановлено до кінця» — запустіть інсталятор ще раз з інтернетом.
• Інсталятор зупинився на кроці — натисніть «Повторити»; повний журнал видно кнопкою
  «Показати подробиці».
• Помилка під час розбору — текст помилки видно в журналі на екрані прогресу.
• Не вистачає пам'яті відеокарти — оберіть якість «4 · швидко».
• Вікно не відкрилося — запустіть «Діагностика InkBeat» і подивіться повідомлення.
• Запис: мікрофон недоступний — Параметри Windows → Конфіденційність → Мікрофон →
  дозвольте доступ програмам. Дубль зсунутий відносно музики — змініть «Затримку».
• Журнал роботи при запуску з ярлика: папка користувача\.inkbeat\inkbeat.log
